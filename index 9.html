プロキシ設定

設定すると、コメント取得・キーワード検索・お気に入り／履歴のサムネイル画像の取得を、すべてこのGoogle Apps Scriptウェブアプリ経由で行います（CORSやブロック対策）。空欄の場合、コメントとサムネイルは直接アクセスしますが、キーワード検索はプロキシ必須です。

GASプロキシの作り方 / 更新方法
  1. script.google.com で新規プロジェクトを作成（既にお持ちの場合はコードを以下のものに差し替え）
  2. 以下のコードを貼り付けて保存
  3. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選択（更新の場合は「デプロイを管理」→鉛筆アイコン→バージョン「新バージョン」を選んで更新。URLは変わりません）
  4. 実行するユーザー「自分」、アクセスできるユーザー「全員」でデプロイ
  5. 発行された /exec で終わるURLを上の欄に入力

※ サムネイル画像はGASが直接バイナリを返せないためBase64化してJSON経由で渡します。以前のバージョンのコードのままだとサムネイルのプロキシ経由取得は動作しません（コメント・検索は従来どおり動作します）。サムネイルもプロキシ経由にしたい場合は、コードを更新して再デプロイしてください。

function doGet(e) {
  var target = e.parameter.url;
  if (!target) {
    return ContentService.createTextOutput(JSON.stringify({error: "missing url parameter"}))
      .setMimeType(ContentService.MimeType.JSON);
  }

  var res = UrlFetchApp.fetch(target, { muteHttpExceptions: true });
  var headers = res.getHeaders();
  var contentType = headers['Content-Type'] || headers['content-type'] || '';

  if (contentType.indexOf('image/') === 0) {
    // 画像はGASがバイナリを直接返せないため、Base64化してJSONで包んで返す
    var base64 = Utilities.base64Encode(res.getContent());
    return ContentService.createTextOutput(JSON.stringify({
      isImage: true,
      contentType: contentType,
      base64: base64
    })).setMimeType(ContentService.MimeType.JSON);
  }

  // JSON/テキスト等はそのまま中継（コメント・検索API用）
  return ContentService.createTextOutput(res.getContentText())
    .setMimeType(ContentService.MimeType.JSON);
}
APIキーの取得方法（任意）
  1. Google Cloud Console でプロジェクトを作成（既存でも可）
  2. 「APIとサービス」→「ライブラリ」から YouTube Data API v3 を有効化
  3. 「認証情報」→「認証情報を作成」→「APIキー」を発行
  4. 発行されたキー（AIzaから始まる文字列）を上の欄に入力

設定すると検索は公式APIを優先的に使用します。空欄の場合は下記のInvidious公開インスタンス（yt.omada.cafeなど）を自動で試すので、APIキーがなくても検索は利用できます。

キーワード検索はYouTube Data APIキー未設定時、既定でyt.omada.cafeを含む複数のInvidious公開インスタンスを自動的に順番に試します。特定のインスタンスを優先したい場合はここに指定してください。検索がうまくいかない場合はブラウザの開発者コンソールに失敗理由が出力されます。
